# AI Website Summarizer (n8n + LLM)

## 🚀 Overview
This project is an AI-powered workflow that extracts website content, processes large text using chunking, and generates structured summaries using LLMs.

## 🔧 Features
- Web scraping
- Text cleaning
- Smart chunking (handles token limits)
- LLM summarization (Groq / LLaMA)
- Google Docs generation
- Email delivery

## ⚙️ Workflow
Form → Fetch Website → Clean Text → Chunk → Summarize → Combine → Google Docs → Email

## 🧠 Tech Stack
- n8n
- Groq API
- Google Docs API
- Gmail API

## 📦 Setup
1. Import workflow.json into n8n
2. Add API credentials (Groq + Google)
3. Run workflow
